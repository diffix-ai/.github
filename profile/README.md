## Diffix

**Autonomous Security Research System.**

Diffix is an early-stage research project exploring autonomous, multi-agent security research for web applications and APIs.

Our goal is to orchestrate specialized agents across vulnerability discovery, controlled exploit validation, evidence collection, and remediation guidance, with independent verification and human review report.

**Research priorities**

- Reliable multi-agent orchestration
- Persistent execution state and task recovery
- Evidence-based vulnerability validation
- Isolated security testing environments
- Reproducible findings and actionable remediation guidance

Diffix is currently in the research and development stage.
